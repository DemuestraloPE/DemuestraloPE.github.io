# Leyes de Newton

Las leyes de Newton relacionan el movimiento de un cuerpo con las fuerzas que
actúan sobre él. Se aplican en marcos de referencia inerciales.

## Segunda ley

Para masa constante, la fuerza neta satisface
\[
\sum \mathbf{F}=m\mathbf{a}.
\]

## Método de análisis

1. Define el sistema y el marco de referencia.
2. Dibuja el diagrama de cuerpo libre.
3. Elige ejes y escribe las componentes de la fuerza neta.
4. Resuelve y verifica unidades y signos.
