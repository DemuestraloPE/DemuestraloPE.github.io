# Oscilaciones

Una oscilación es un movimiento que se repite alrededor de una posición de
equilibrio. Para un oscilador armónico ideal,
\[
x(t)=A\cos(\omega t+\phi),\qquad \omega=\sqrt{\frac{k}{m}},
\]
para una masa \(m\) unida a un resorte de constante \(k\).

## Conceptos

- Amplitud, periodo, frecuencia y fase.
- Energía cinética y potencial.
- Oscilaciones amortiguadas y forzadas.
