# Derivadas

La derivada mide la tasa de cambio local de una función y, geométricamente,
corresponde a la pendiente de la recta tangente cuando esta existe.

## Definición

Para una función \(f\), la derivada en \(a\) se define mediante el límite

\[
f'(a)=\lim_{h\to 0}\frac{f(a+h)-f(a)}{h},
\]

si el límite existe.

## Contenidos por desarrollar

- Interpretación geométrica y como tasa de cambio.
- Reglas de derivación y regla de la cadena.
- Teoremas del valor medio y aplicaciones a extremos.

## Ejemplo

Para \(f(x)=x^2\), el cociente incremental es
\(\frac{(x+h)^2-x^2}{h}=2x+h\); al tomar \(h\to0\), se obtiene \(f'(x)=2x\).
